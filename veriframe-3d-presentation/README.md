# VeriFrame — 3D Presentation Hero / First Page

An interactive, high-performance WebGL 3D title page and slide experience for the **VeriFrame** AI Media Forensics Platform.

## 🚀 How to Launch
- **Double click** `launch.bat` (or open `index.html` directly in any modern browser: Chrome, Edge, Brave, Firefox, Safari).
- Or from terminal: `Start-Process "veriframe-3d-presentation\index.html"`

---

## ✨ Features on the 3D First Page

### 1. Interactive 3D Holographic Forensic Core
- **Three-layer Biometric Mesh**: Glowing inner neural core, icosahedron geodesic cage, and 68-point facial landmark emulation nodes.
- **Dynamic Laser Sweep**: Real-time vertical laser disc scanning up and down with glowing intersection effects.
- **Concentric Gyroscopic Tech Rings**: Tri-axis gyroscopic rings with rotating satellite telemetry drones.
- **Floating Particle Field & Cyber Grid**: Over 2,000 depth particles with subtle nebula motion and infinite perspective floor grid.

### 2. Camera & Interactive Controls
- **Mouse Parallax**: Fluid camera tracking with lerp interpolation responding to cursor movement.
- **3D Free Orbit Mode**: Click `[3D FREE ORBIT MODE]` or press `O` to unlock full 360-degree interactive camera orbit and zoom.
- **Theme Color Shaders**: Switch dynamically between:
  - `CYBER HOLOGRAM` (Electric Cyan & Deep Blue)
  - `DEEPFAKE HEATMAP` (Warning Neon Crimson & Amber)
  - `NEURAL MATRIX` (Terminal Emerald Green)
  - `TITANIUM GOLD` (Luxury Titanium & Gold)

### 3. Integrated Forensic Scan Simulator
- Click `[RUN FORENSIC SCAN SIMULATION]` (or hit `Spacebar`):
  - Accelerates the 3D biometric core rotation.
  - Simulates the real-time pipeline: Adaptive Frame Sampling -> Landmark Extraction -> Cross-Efficient-ViT Inference -> Temporal Calibration.
  - Displays forensic confidence score (98.4%), authenticity verdict, and cryptographic SHA-256 report verification hash.

### 4. Native Web Audio Synthesizer
- Built using native Web Audio API (zero external sound files needed).
- Sci-fi laser sweeps, hover ticks, and success chimes.
- Toggle sound on/off with the `AUDIO` button or press `M`.

### 5. Keyboard Shortcuts
- `Space`: Run Forensic Scan Simulation
- `F`: Toggle Fullscreen Presentation Mode
- `O`: Toggle 3D Free Orbit / Camera Lock
- `M`: Toggle Sound FX on/off
- `Mouse Drag`: Orbit 3D scene (when in orbit mode)
